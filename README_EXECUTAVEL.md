# Como usar o executável para Windows

1. Copie a pasta do projeto para o PC cliente.
2. Execute o arquivo iniciar_oficina.bat.
3. O sistema abrirá automaticamente no navegador em http://127.0.0.1:8000/index.php.

## Requisitos
- PHP instalado e disponível no PATH, ou
- XAMPP com Apache e MySQL iniciados.

## Observação
Se o PHP não estiver instalado no computador, o arquivo ainda informa o que fazer, mas o sistema também pode ser usado pelo XAMPP.
