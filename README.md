# 🚗 EDG Sistema de Gestão de Oficina.

Sistema web para gerenciamento de oficina mecânica, desenvolvido com o objetivo de organizar e facilitar o controle das principais informações e atividades de uma oficina.

---

## 📋 Sobre o projeto

O **EDG Sistema de Gestão de Oficina** é uma aplicação web desenvolvida para auxiliar no gerenciamento de uma oficina mecânica.

O sistema busca centralizar informações relacionadas a clientes, fornecedores, peças e serviços de manutenção, proporcionando uma organização mais eficiente dos dados.

O projeto também possui finalidade acadêmica e de aprendizado, permitindo aplicar conceitos de desenvolvimento web, banco de dados, programação e gerenciamento de projetos.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

- Organizar os dados da oficina;
- Facilitar o cadastro e consulta de clientes;
- Controlar fornecedores;
- Gerenciar peças;
- Registrar informações relacionadas à manutenção;
- Centralizar as informações do sistema;
- Aplicar conceitos de desenvolvimento de sistemas e banco de dados.

---

## 🚀 Funcionalidades

Atualmente, o sistema contempla funcionalidades relacionadas a:

- 👤 Cadastro de clientes;
- 🏢 Cadastro de fornecedores;
- 🔧 Cadastro de peças;
- 🛠️ Controle de manutenção;
- 📋 Solicitações de serviços;
- 🔎 Consulta de informações;
- 💾 Persistência de dados em banco de dados.

> 🚧 O projeto encontra-se em desenvolvimento e novas funcionalidades poderão ser adicionadas.

---

## 💻 Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

| Tecnologia | Utilização |
|---|---|
| PHP | Desenvolvimento da aplicação |
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização |
| JavaScript | Interatividade |
| Bootstrap | Interface e componentes visuais |
| MySQL / MariaDB | Banco de dados |
| Apache | Servidor web |
| Composer | Gerenciamento de dependências |
| WAMP | Ambiente de desenvolvimento |
